## Obsidian（新手常用）

| 快捷键 | 做什么 |
| --- | --- |
| **Ctrl + N** | 新建笔记 |
| **Ctrl + O** | 快速打开（按文件名搜） |
| **Ctrl + E** | 编辑 / 预览切换 |
| **Ctrl + Shift + F** | 全文搜索 |
| **Ctrl + P** | 命令面板（不知道功能时先按这个） |
| **Ctrl + Click** | 点开 `[[双链]]` |
| **[[笔记名]]** | 双向链接：输入 `[[` 再选笔记 |

### 每日笔记（Daily）

- 本库的日记在文件夹 `Daily/`，文件名形如 `2026-08-24.md`。
- Save Dates 点「加入」时，会往当天 Daily 里追加一行；完整详情在 `Events/`。
- 手动写当天流水：左侧打开 `Daily/` 里今天的文件，或 `Ctrl+O` 输入今天的日期。

### 本库里怎么找东西

- 日程细节 → `Events/`
- 还没整理 → `Inbox/`
- 长期分类 → `课程/` `GSR/` `生活/`
- 迷路了 → 打开 [[00-开始这里]]

## Windows 常用

| 快捷键 | 做什么 |
| --- | --- |
| **Win + D** | 显示桌面 |
| **Win + E** | 打开资源管理器 |
| **Win + L** | 锁屏 |
| **Alt + Tab** | 切换窗口 |
| **Ctrl + C / V / Z** | 复制 / 粘贴 / 撤销 |
| **Win + V** | 剪贴板历史（需先在系统设置里打开） |
